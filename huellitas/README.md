# Huellitas 🐾

Página web de adopción de perros y gatos, hecha con React + Vite.

## Cómo ejecutarla

```bash
npm install
npm run dev
```

Abre la dirección que aparece en la terminal (normalmente http://localhost:5173).

## Versión para publicar

```bash
npm run build
```

Los archivos finales quedan en la carpeta `dist/`.

## Estructura

- `src/App.jsx`: contenido y secciones de la página
- `src/App.css`: estilos de la página
- `src/index.css`: colores, tipografías y estilos globales
- `public/`: imágenes e íconos
